## Ownership by Area

- `backend/` API control plane and orchestration logic
- `simulation/` quantum and channel simulation primitives
- `protocols/` protocol implementations and registries
- `adaptive/` AQShield decision logic and policy layers
- `authentication/` communication trust verification
- `metrics/` security and performance measurement
- `attacks/` adversarial scenario injectors
- `experiments/` reproducible campaign execution
- `database/` storage integration and persistence support
- `frontend/` operator dashboard and visualizations
- `docs/` design, research, architecture, and meeting artifacts
